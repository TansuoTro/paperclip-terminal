# ANNEAL · 回形针作业终端

原创终端式放置游戏，使用 TypeScript、Preact/signals、Three.js、Canvas 2D 和 WebAudio。纯前端，无账号、无服务器、无追踪，可发布到 Netlify。

## 运行

需要 Node.js 20.19+ 或 Node.js 22+。

```bash
npm ci
npm run dev
```

打开终端输出的本地地址，点击“初始化”。浏览器需要这次点击来启动合成音乐。

```bash
npm test          # 模拟逻辑、资源约束、存档和完整通关回归
npm run balance  # 自动玩家：只用正常游戏指令走到结局
npm run build    # TypeScript 检查 + 生产打包
npm run preview  # 本地预览 dist/
```

浏览器集成检查：

```bash
npx playwright install chromium
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
# 另一个终端
npm run test:browser
npm run test:mobile  # 5 种手机/平板尺寸 × 三幕，包含横屏、触控与折叠工具
```

检查会覆盖开局点击、2D/3D 切换、五个 3D 场景、探测器面板及手机尺寸，并把截图写到 `artifacts/`。后期截图使用测试存档，不等同于人工玩完游戏；完整通关由独立模拟回归验证。

## 手机界面

宽度不超过 600px 时使用紧凑单列，账目和操作优先；601–900px 使用两列。视口按屏幕高度限制为约 210–300px，不再占满首屏。按钮与加减点的触控高度至少 44px；滑条、菜单、安全区和动态视口高度均有单独适配。

底部“日志”“命令”默认收起，点击展开；手机命令栏提供执行按钮。小尺寸示意图使用紧凑读数格，完整遥测仍可通过“数据”查看。桌面端保留原有多列和日志布局。

手机布局已通过 Chromium 触控模拟检查；尚未在实体 iPhone/Safari 上验证浏览器工具栏和输入法行为。

## 怎么玩

1. **台面**：点击成型，出售库存，调整价格，买自动机与营销。别让钢丝耗尽。
2. **厂区**：完成“自我审计”进入第二幕。用信任分配处理器/内存，用运算与洞察研究项目。硬件可免费重新分配，但缩减内存会丢弃多余运算。
3. 运算满载后才产生洞察；可以暂缓购买项目积累洞察。若某项目价格超过运算上限，增加内存或研究存储升级。
4. 解锁能源与物质系统。供电不足会降低生产；太阳能和电池分别解决功率与储能。
5. **星网**：进入第三幕，研究并发射复制体。航行、探索、采集必须均大于零。分配复制、工厂、拉丝、防护和战斗点数，逐步占据宇宙质量。
6. 达到最后的质量门槛后，购买“终末退火”完成本局。

光学视图是 3D 实景；示意图展示生产流、各自独立标度的历史趋势及资源瓶颈。所有可操作内容都有 DOM 按钮，不依赖点击 Canvas，PLAIN 模式可以完成游戏。

## 音乐

没有音频素材文件。振荡器、噪声、滤波器与运行时合成混响生成全部背景音乐及音效。六个音乐层随界面进度加入，三幕使用不同调式与节拍；音频时钟预调度，不依赖画面帧率。系统菜单可单独调整总音量、音乐和音效。

## 存档

- 每 10 秒、页面隐藏和退出时保存到浏览器 localStorage。
- 保留上一份备份；当前存档损坏时尝试恢复备份。
- 系统菜单可导出/导入 Base64 存档。导入包含格式、有限数值、分配点结构与校验和检查。
- 离线最多补算 8 小时，按 60% 效率结算；不会自动替玩家购买项目或跨越确认点。
- 存档只属于当前浏览器站点；切换域名需手动导出/导入。请不要在多个标签页同时操作同一局。

## 发布到 Netlify

生产文件已生成在 `dist/`。两种方式：

- **手动上传**：将 `dist/` 文件夹拖入 Netlify 的手动部署页面。
- **连接 Git 仓库**：构建命令 `npm run build`，发布目录 `dist`。项目根目录已有 `netlify.toml`。

无需 API 密钥、环境变量或服务端函数。当前工作仅生成本地文件，不会自动创建公开站点。

## 实现边界

这是可完整通关的第一版，不是原作源码移植。60 个研究项目、三幕经济、双视图、五个 3D 尺度场景、调度试验、探测器属性、战斗、音乐及存档已实现。

场景采用程序化简约几何，不包含美术素材；星系与宇宙网是艺术化抽样而非天文模拟。尚未做多人/云存档、长期设备性能认证、原生移动端适配、人工五小时连续游玩平衡校准。自动玩家耗时只用于回归，不代表所有真人玩家的通关时间。

## 代码

- `src/sim/`：纯模拟、命令、内容表与存档编码。
- `src/view2d/`：DOM 控制台与 Canvas 2D 场景。
- `src/view3d/`：按需加载的独立尺度壳、单 WebGL 上下文合成。
- `src/audio/`：合成器、配乐调度与音效。
- `scripts/policy.ts`：不注入资源的自动玩家策略。
- `tests/sim.test.ts`：回归测试。
- `DESIGN.md`：与当前第一版对应的设计说明。
